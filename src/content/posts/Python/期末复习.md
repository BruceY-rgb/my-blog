## 基础知识

### 数制

- 十进制转二进制
  - 整数部分：除二取余
  - 小数部分：乘二取余
- 二进制转十六进制

### 数的编码

- 原码
- 反码：若符号位产生进位，需要将进位循环加到结果最低位
  - 正数反码与原码相同
  - 负数反码为除了符号位外各位取反
- 补码：若符号位进位，直接丢弃
  - 正数补码与原码相同
  - 负数补码为除符号位各位取反然后在最后一位加一

## Python基本数据类型及表达式

- 对象三要素
  - `identity`:对象的内存地址，函数`id()`
  - `type`:对象的类型，，函数`type()`
  - `value`:对象的值，直接查看即可
- 主要数据类型
  - 不可变类型
    - `int`
    - `float`
    - `complex`
    - `bool`
    - `str`
    - `tuple`
  - 可变类型(内容可以在原地修改，无需创建新对象，**对象的id不变**)
    - `list`
    - `set`
    - `dict`

> 对不可变对象执行的任何修改操作实际上是创建一个新的对象

### 整型
- 理论上可以表示的整数范围是无限的
- 进制转换函数(最终得到的是一串字符串)

```python
bin(5)        # '0b101'
oct(11)       # '0o13'
hex(29)       # '0x1d'
```

- 字符串转整数(最终得到的数据类型是int)
  - 第一个参数是要转化的字符串对象
  - 第二个参数是这个字符串本身的进制(默认为十进制)

```python
int(`101`, 2) # 5
int(`101`, 8) # 65
```

### 浮点型

- 字面量形式    
  - 小数形式：1.23
  - 科学计数法：1.24e7.1,2e-4

> e的前后都不能空，e的后面要整数

- `float()`将某些类型数据转换成浮点数
- 与整数不同，浮点数存在范围限制，超出会产生溢出错误
- 不是所有的实数在计算机里都可以精确表达，会存在误差

```python

0.1 + 0.2  # 结果是 0.30000000000000004，不是 0.3
```

### 复数

- 由实部和虚部两部分组成，虚部用j表示

```python

# 创建函数

# 访问实部和虚部
(1+2j).real # 1.0(float)
```

> complex.real和complex.imag返回的类型是float

### 布尔型

- 布尔类型只有True和False(注意开头字母大写)

  - `True`等价于1
  - `False`等价于0

```python

False + 1  # 1
```

- 不同类型数据混合运算时，遵循`bool->int->float->complex`的方向自动转换。这样做就可以保证结果不受精度损失

- `split()`:用一个字符或子串将一个字符串分隔成若干字符串并以**列表**形式返回
- `find()`:在字符串中查找子串，返回**首次出现的位置索引**，如果找不到`-1`

> `find()`找不到对应子串不会报错；`index()`找不到对应子串时抛出异常

- 修改大小写
  - `title()`:将字符串中每个单词的首字母变成大写字母
  - `upper()`:将字符串中所有字母变成大写字母
  - `lower()`:将字符串中所有字母变成小写字母

```python

name.title()   # "John Johnson" (每个单词首字母大写)
name.upper()   # "JOHN JOHNSON" (全部大写)
name.lower()   # "john johnson" (全部小写)
```

> 使用这些方法之后，原来的字符串本身不会发生变化，如果我们想修改字符串，必须要给字符串本身重新赋值：`name = name.upper()`

- 删除空格
  - `strip()`
  - `rstrip()`
  - `lstrip()`
- `replace()`:替换字符串中的子串

```python
s = 'This is a test.'
s.replace('is', 'eez')  # "Theez eez a test."
```

### 序列

```python
for item in sequence:
    print(item)

    print(sequence[i])
```

- 删除
  - `pop(i)`:移除并返回指定位置的元素(默认末尾)，索引为`i`
  - `remove(x)`:移除列表中第一个值为`x`的元素
  - `clear()`:清空列表中的所有元素(但是不会删除列表本身)

```python
# pop() - 弹出
a = [2, 3, 5, 7, 11]
print(a.pop())   # 11

# remove() - 删除第一个匹配元素
a = [2, 3, 5, 7, 5, 11]
a.remove(5)
print(a)  # [2, 3, 7, 5, 11]

# clear() - 清除
a.clear()
print(a)  # []
```

> 在使用remove方法的时候，如果**要删除的数据不在列表中**，则会 **发生错误**

<aside class="admonition example">
这里有一个典型的关于`remove()`的问题

```python
a = [1,2,3,3,5]
for i in a:
    if i == 3:
        a.remove(i)

print(a) # [1,2,3,5]
```

- 找到第一个3之后删除
- 这个3后面的元素会往前移动，接下来的这个3因为索引递增会被跳过
- 因此这段代码无法删除全部的3

```python
a = [1,2,3,3,5]
for i in a[:]:
    if i == 3:
        a.remove(i)
    print(a) # 1,2,5
```

- 这里的`a[:]`的作用是创建列表副本，相当于每次循环都会在副本中去遍历元素，不会遗漏
</aside>

### 列表推导式

- `[expression for item in iterable]`
  - 这里的`expression`可以是多种形式，基本表达式、函数、条件表达式等

```python
nl = [2 * number for number in range(1, 6)]
# [2, 4, 6, 8, 10]
slen = [len(s) for s in ['hello', 'world', 'python']]
# [5, 5, 6]
cl = [number if number % 2 else -number for number in range(1, 8)]
# 结果: [1, -2, 3, -4, 5, -6, 7]
```

- 条件过滤
  - `[expression for item in iterable if condition]`
  
```python
nl = [number for number in range(1, 8) if number % 2 == 1]
# 结果: [1, 3, 5, 7]
```

> 新列表的元素个数一定≤原有列表元素的个数

### 字典

- 字典的建必须是不可变对象，比如数字、字符串、元组

> 这里要注意元组也是不可变对象

- 创建字典
  - `{}`创建空字典
  - `s = {'name':'Alice', 'age':30}`
  - `s = dict(name='Alice', age=30)`
  - `zip()`组合，`dict(zip(keys, values))`


<aside class="admonition warning">
- 第二种方式不能处理键是整数的情况

```python
s = dict(name='Alice',age = 30) # ok
s = dict(name='Alice',1 = 30) # error
```
</aside>
- 访问字典
  - `[]`运算符：若提供的键不存在，会抛出`keyerror`异常
  - `get(key, default_value)`方法：若提供的键不存在，返回`None`(或指定的`default_value`)

> `get()`方法是字典的成员方法，不是Python全局内置函数

- 字典修改与更新
  - `student['age'] = 21`
    - 如果键已经存在就更新其值
    - 这个键不存在则添加这个新的键值对
  - `student.update({'id':'1001', 'grade':'A'})`
    - 修改存在的键对应的值
    - 添加新的键值对到字典中
- 删除数据
  - `dict.pop(key, default_value)`:如果不设置`default_value`，那么指定键不存在就会 **抛出异常**；若设置后会返回`default_value`
  - `del student['age']`语句：直接删除这个键值对
  - `student.clear()`:清空这个字典，但是保留了一个空字典
- 字典的遍历
  - dict.keys():返回由所有 键组成的字典视图对象
  - sict.values():返回由所有值组成的字典视图对象
  - dict.items():返回由**所有键值对(key, value)**元组组成的字典视图对象可使用for循环进行遍历返回


### 集合

- 集合可以看做是无序、不重复的元素集，可以看做是只有键没有值的特殊字典
- 集合的字面量也是用`{}`包裹，常用于去重和逻辑运算(交并补)
- 集合中的元素是必须是不可变类型(必须要求元素是可哈希的)

> `{}`是创建一个空字典，不能创建空集合。创建空集合只能使用`{}`

- 使用`set`可以将列表或元组转换成集合
  - `prime = set([10,1,2,3,4])`
  - 结果是：{10, 3, 5, 7, 11}

> 转换的时候会自动去除重复的元素

**操作集合元素**

- 查询元素：使用`in`或`not in`关键字判断元素是否存在于集合中，效率极高
- 遍历元素：通过`for`循环可以遍历集合中**所有元素**，但是**顺序是不确定的**
- 增加元素
  - `add()`:添加单个元素
  - `update()`:以**可迭代对象**形式添加多个元素
- 删除元素
  - `discard()`:如果存在删除，**不存在无效果**
  - `remove()`:如果存在删除，不存在**抛出异常**
  - `pop()`:如果存在删除**任意一个元素并返回**，不存在会**抛出异常**
  - `clear()`:删除所有元素，剩下一个空集合

```python
s = {10, 20, 30, 40}

for x in s:
    print(x) # 输出顺序是不确定的

s.add(50)
s.update([60,70]) # 添加多个元素s = {10,20,30,40,50,60,70}
s = set()
s.update("abc") # s = {'a', 'b', 'c'}
s.discard(10) # ok
s.discard(80) # ok
s.remove(10) # ok
s.remove(80) # 抛出异常
s.pop() # 删除任意一个元素并返回
s.clear() # 删除所有元素，剩下一个空集合
```

- 字典的排序操作：`sorted()`函数

> `sorted()`函数不只可以排列列表，元组、字符串、字典、集合全部都能排序，排序后返回的结果都是列表

## 文件

### 打开文件

- `fp = open(filename, mode, encoding=None)`
  - `filnename`: 文件名
  - `mode`: 文件打开模式
  - `encoding`: 文件编码方式
- open操作成功之后返回一个文件对象
- 后续的写操作通过这个文件对象完成

> 建议显式制定`encoding = "utf-8"`

**常考模式**

1. `r`:只读模式
    - 文件必须存在，不存在会抛出异常
    - 不允许写入
2. `w`:覆盖写模式
    - 文件不存在就创建新文件
    - 文件存在：**清空**源文件内容
3. `a`:追加写模式
    - 文件不存在创建新文件
    - 文件存在：在文件末尾追加内容
    - 不会清空原文件
4. `x`：独占创建模式
    - 文件不存在创建新文件
    - 文件存在：抛出异常
5. `b`:二进制模式
    - 读写的单位是`byte`，文本文件是 **字符串**
    - 常组合使用`ab`,`wb`,`rb`
6. `+`:读写模式，需要和其他模式组合
    - `r+`读写，文件必须存在
    - `w+`读写，文件不存在则创建，存在则清空
    - `a+`读写，写入时追加到末尾

  - 精确导入：`from math_tools import PI`

  - 别名导入：`import math_tools as mt`
