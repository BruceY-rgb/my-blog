# AstroPaper base

This site is migrated from Hexo using the upstream [AstroPaper](https://github.com/satnaing/astro-paper)
v6.1.0 structure as its base: Astro content collections, a minimal responsive reading layout,
dark mode, RSS, sitemap, Pagefind search, and Shiki highlighting.

The template has been deliberately simplified for a Chinese technical notebook. There are no hero
cards, gradients, particle effects, or client-side page transitions. The additions in this repository
focus on stable legacy URLs and asset compatibility.
