## 词法分析

- A deterministic finite automaton (DFA) can be in multiple states simultaneously for a single input string.

> False. 这道题目的意思是对于同一个输入串，一个DFA可以同时处在多个状态中。这很明显是错误的

- NFA转化为DFA理论上的最大值是 $2^n$,但是实际上都远小于这个理论值
- Which mathematical operation is used to find all NFA states reachable from a set of states without consuming any input characters?

> ϵ-closure.这道题目的意思是哪个数学操作用来找出：从一组NFA状态出发，在不消耗任何输入字符的情况下，可以到达的所有状态？

- 在词法分析器Lex中，采用何种机制处理不同上下文场景，例如注释块内部与注释块外部的区分？

> Start states.不同的上下文要使用Start states来处理。Start states实际上就是Lex词法分析器里面的模式切换

- 对 DFA 中两个状态 s1 和 s2，如果从 s1 出发读任意字符串 σ，是否接受的结果，和从 s2 出发读同一个字符串 σ 的结果永远一样，那么 s1 和 s2 是等价状态。

## 语义分析

- 语义分析的三个主要功能
  - 将变量的定义与其使用关联起来
  - 检查每个表达式是否具有正确的类型
  - 将抽象语法转换为适合生成机器代码的更简单表示形式

> AST是语法分析阶段生成的

- 函数式符号表不需要显式`beginScope`和`endScope`，因为创建新作用域的时候会保留旧的符号表指针；离开作用域的时候可以直接回到旧表
- `type checking`阶段遇到`arr[i]`表达式的时候要先检查被索引对象是否为有效数组，再检查下标i是不是合法索引类型，最后推导整个`arr[i]`的元素类型

## 中间表示

- IR语言没有单目运算
- Tree IR里的CJUMP指令，当条件为假的时候不是总会fall through,在后端坐代码重排的时候才会做这种操作
- Tiger中创建的record,数组,字符串都分配在堆上，栈上只存放 **指向堆的指针**，不会把记录本体放在栈帧里
  - 函数返回的时候只会释放栈局部变量才会随函数释放，堆记录不会
- CALL节点`CALL(func_exp, [arg1, arg2, ..., argn])`
  - 先计算函数子表达式`func_exp`
  - 再按照从左到右以此计算每一个参数表达式
  - 全部计算完成后执行函数调用，产生返回值

> 保存函数返回地址不是Tree IR层面的工作，是IR翻译成回边代码的操作

- CALL节点必须被`move to the top`因为多个CALL节点在一个表达式中出现会覆盖return-value寄存器

**活动记录**

```
function outer() {
    var x = 10

    function inner() {
        return x + 1
    }

    return inner
}
```

- 如果语言同时支持嵌套函数和函数作为变量(值传递)，那么某些局部变量(例如上述代码中的x)必须比它们所在的外层函数调用活得更久
- FP指向当前栈帧的`base`，是栈的最高起始地址；SP包含栈的最低地址
- 被调用函数callee可以随便覆盖、修改这类寄存器，没有义务回复原值。caller-register必须由caller保存
- On the MIPS, registers 16–23 are treated as callee-save.
- Leaf procedures often do not allocate their own stack frame.
- 标签 label 和临时变量 temp 放在同一个 Temp 模块
- escape analysis必须在parsing之后就执行，在语义分析开始之前执行。如果等到语义分析之后再进行就没有意义了
- The outgoing arguments area is allocated by the current function at the bottom of its stack frame to place arguments for the subsequent functions it intends to call.

- The reorder function extracts side effects (statements) from expressions and returns them as a single sequence to be executed before the expression list.

- A variable that is defined but never used in the program does not interfere with any other live variables.

> False.变量定义之后确实没有活跃区间，但是定义它的那条指令本身仍然需要一个寄存器来写结果，这个寄存器也不能占用仍然活跃的变量。所以即使活跃区间长度为0，仍然可能与其他活跃变量冲突

- 当寄存器有很多的时候，要激进地进行寄存器合并

## 垃圾回收

- In a mark-and-sweep garbage collector, the roots of the object graph are the program variables currently in scope.

> True.Roots通常就是程序当前能够直接访问到的指针变量，包括当前作用域变量、栈变量、全局变量和寄存器中的指针

- During mark-and-sweep, the sweep phase reclaims every node that was not marked in the mark phase

> False. reclaim的意思是收回

- Updating reference counts adds only negligible run-time cost to pointer assignments

> False. negiligible的意思是微不足道的，实际上引用计数的开销是非常大的

- Cheney的复制算法不需要显式栈或者队列，只需要两个指针
- Generational GC建立在一个经验观察上：大多数对象很快就会死亡。young generation经常清理，old generation较少清理
- The forwarding pointer in a copied object often repurposes the first field
- Pointer reversal把对象原本指向子节点的字段临时改成指回父节点的连接，从而不调用DFS栈，所以它临时存的是DFS stack links
- Data-flow aggregation of increments/decrements或者defered reference counting可以减少reference count的的运行时间.通过编译器数据流分析或延迟引用计数技术，系统能够消除基本块内的中间指针修改操作（对增减计数进行合并处理），大幅减少运行时执行的计数器更新次数。
- generational GC的remembered set记录了从older到younger的指针
- Semi-depth-first variant 的目标是：尽量让父对象和至少一个子对象在to-space中相邻，它不是完全 DFS，但会模仿 DFS 的布局效果
